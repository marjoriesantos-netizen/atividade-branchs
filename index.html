Sobre

Este projeto foi desenvolvido para praticar o uso de branches, commits e GitHub.

A atividade demonstra como diferentes funcionalidades podem ser desenvolvidas em branches separadas e posteriormente integradas ao projeto principal.

O objetivo é aprender na prática o fluxo de desenvolvimento utilizando Git e GitHub.
